# Gustavo Rhythm HUD — protótipo Geode

Projeto-fonte inicial. O disco fica oculto até a previsão real ser implementada.

## Como gerar o arquivo .geode (sem instalar nada)
1. Crie um repositório no GitHub e suba todos os arquivos desta pasta (incluindo `.github`).
2. Vá em Actions > "Build Geode Mod" > Run workflow.
3. Quando terminar, baixe o artifact "Build Output": dentro tem o `gustavo.rhythm-hud.geode`.
4. Coloque o .geode na pasta `geode/mods` do Geometry Dash.

## Como compilar localmente
Instale o Geode CLI e SDK e rode `geode build` na pasta do projeto.
Docs: https://docs.geode-sdk.org/
